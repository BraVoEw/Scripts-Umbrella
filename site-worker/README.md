# Форма «Идея или баг» → Telegram-бот

Сайт шлёт форму в воркер на Cloudflare, воркер пишет тебе в Telegram. Ключ бота живёт только в Cloudflare, на сайте и в этом репозитории его нет.

## Что умеет бот
Под каждым сообщением с сайта две кнопки:
- **⭐ В «Спасибо»** — человек сразу появляется в блоке «Спасибо» на сайте (если оставил ник). Ответь на сообщение своим текстом, чтобы поменять подпись.
- **🚫 Забанить** — с его адреса и ника больше ничего не придёт, на сайте он увидит «Ты заблокирован».

Команды (меню по кнопке «/» в чате с ботом):
- `/bans` — кто забанен, `/unban 2` или `/unban @nick` — разбанить
- `/thanks` — список «Спасибо», `/addthanks @nick за что` — добавить, `/unthanks 2` — убрать
- `/help` — подсказка

Нажимать кнопки и писать команды можешь только ты: бот проверяет твой ID.

## Настройка (уже сделано: бот, CHAT_ID, BOT_TOKEN, ALLOW_ORIGIN)
1. **Код:** воркер → **Edit code** → вставить `feedback-worker.js` целиком → **Deploy**.
2. **Хранилище:** слева **Storage & Databases → Workers KV → Create** → имя `bravoew-feedback` → **Create**.
3. **Подключить хранилище:** воркер → **Bindings** → **Add binding** → **KV namespace** → Variable name: `DB`, namespace: `bravoew-feedback` → **Add binding** (или Save and deploy).
4. **Пароль настройки:** **Settings → Variables and Secrets → Add** → `SETUP_KEY`, тип **Secret**, значение — любой придуманный пароль (латиница и цифры).
5. **Подключить кнопки:** открой в браузере `https://<адрес-воркера>/setup?key=<твой пароль>`.
   Должно показать `"webhook": "подключён"` и `"commands": "добавлены"`.
6. Напиши боту `/help` — он ответит списком команд.

## Лента донатов на сайте
На сайт попадают последние 10 донатов: ник, сумма, сообщение. Ссылки вырезаются, мат убирается, пустой ник показывается как «Аноним». Любой донат можно скрыть с сайта: `/dons` покажет список, `/hidedon 2` скроет. USDT сюда не подключён: на кошелёк приходят и обычные переводы.

**DonationAlerts**
1. На https://www.donationalerts.com/application/clients создай приложение. Redirect URL: `https://<адрес-воркера>/da-callback`.
2. В воркере добавь Secret: `DA_CLIENT_ID` (ID приложения) и `DA_CLIENT_SECRET` (его ключ, API key).
3. Открой `https://<адрес-воркера>/da-login?key=<SETUP_KEY>` и разреши доступ. Воркер сам хранит и продлевает токен.

**Donatello**
1. В панели Donatello найди API-ключ (Токен) и добавь его в воркер как Secret `DONATELLO_TOKEN`.

После этого открой `https://<адрес-воркера>/setup?key=<SETUP_KEY>` ещё раз, чтобы в меню бота появились новые команды, и напиши боту `/dons`: в начале ответа будет видно, если какой-то сервис не подключён.

## Безопасность
- Токен бота, твой ID и пароль — только в Cloudflare как Secret.
- Адреса людей не хранятся в открытом виде, только их хеш.
- Не больше 5 сообщений в час с одного адреса, скрытое поле-ловушка для ботов, запросы принимаются только с сайта.
