# Сервер «Найти тиммейта» для Build Brain

Хранит открытые пати и заявки на вход. Скрипт хоста сам приглашает в пати, скрипт игрока сам принимает приглашение. Сервер только передаёт между ними номер пати.

## Развернуть (один раз)

1. **Воркер:** Cloudflare → **Workers & Pages → Create → Create Worker** → имя `bb-party` → **Deploy**. Потом **Edit code** → вставить `party-worker.js` целиком → **Deploy**.
2. **База:** слева **Storage & Databases → D1 SQL Database → Create** → имя `bb-party` → **Create**. Таблицы воркер создаст сам при первом запросе.
3. **Подключить базу:** воркер `bb-party` → **Bindings → Add binding → D1 database** → Variable name: `DB`, база: `bb-party` → **Add binding**.
4. **Проверка:** открой в браузере `https://bb-party.<твой-поддомен>.workers.dev/parties`. Должно показать `{"now":...,"parties":[]}`.
5. Скинь этот адрес, он пойдёт в скрипт.

## Аватарки (ключ Steam Web API)

Скрипт сам не может скачать картинку из Steam, поэтому аватарки отдаёт воркер.

1. Открой https://steamcommunity.com/dev/apikey, в поле Domain впиши адрес воркера (например `bb-party.bravoyt11.workers.dev`), согласись с условиями и получи ключ.
2. Воркер `bb-party` → **Settings → Variables and Secrets → Add** → имя `STEAM_KEY`, тип **Secret**, значение: ключ → **Deploy**.
3. Ключ живёт только в Cloudflare, в скрипте и в репо его нет. Аватарки кешируются на сутки, Steam спрашивается редко.

## Обновить код

Воркер → **Edit code** → заменить всё на новый `party-worker.js` → **Deploy**. Таблицы и данные сохраняются.

## Лимиты бесплатного тарифа

- Воркеры: 100 000 запросов в сутки на весь аккаунт, вместе с ботом обратной связи.
- D1: 100 000 записей и 5 млн чтений в сутки.
- Сброс в 00:00 UTC. Если упрёмся, тариф Workers Paid снимает это ограничение.

Скрипт спрашивает сервер только пока открыта вкладка «Пати», висит твоя пати или ты ждёшь приглашения.

## Что хранится

Steam ID, ник, ранг, режим, нужные роли и язык. Пати живёт 10 минут, заявка на вход 2 минуты, потом удаляются.
